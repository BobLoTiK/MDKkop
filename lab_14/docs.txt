MDK: старт в машинном обучении

Описание курса.
Курс «MDK: старт в машинном обучении» состоит из пятнадцати практических задач. Каждая задача — это отдельное занятие длительностью два академических часа: короткая теория не дольше пятнадцати минут и основная часть за компьютером. Правило курса простое: код набирается заново на каждом занятии, копировать заготовки с прошлых работ нельзя, на конкурсе готовых шаблонов не будет.

Порядок задач.
Задачи 2–4 знакомят с ручной обработкой данных: статистика по CSV без библиотек, массивы numpy, таблицы pandas с пропусками и графиками. Задачи 5–6 — первая модель и градиентный спуск, написанный руками. Задачи 7–9 — нейрон на numpy, тот же нейрон на PyTorch и переобучение с тремя способами лечения. Задачи 10–12 — первая настоящая нейросеть на MNIST, готовые предобученные модели и дообучение на своих картинках. Задачи 13–15 — работа с локальной языковой моделью, мини-RAG по своим документам и финальный проект с веб-интерфейсом.

Оборудование.
Отдельная видеокарта не требуется: все занятия идут на процессоре. Минимальная конфигурация — ноутбук с 8 ГБ оперативной памяти и двухъядерным процессором; на такой машине эпоха на MNIST занимает около минуты. Виртуальное окружение создаётся один раз на первом занятии: python -m venv .venv, затем установка пакетов из requirements.txt. Все скрипты курса запускаются из VS Code.

Расписание и дедлайны.
Занятия проходят по вторникам, начало в 10:40, аудитория 214. Консультации — там же, аудитория 214, по четвергам с 16:00 до 18:00. Дедлайн сдачи всех лабораторных работ — 25 декабря, после этой даты работы принимаются только с письменного разрешения заведующего отделением. Каждая работа сдаётся личной защитой: студент запускает скрипт и объясняет, что делает каждая строка.

Оценивание.
За лабораторную работу ставят зачёт, если скрипт запускается без ошибок и студент отвечает на вопросы по коду. Оценка «отлично» требует выполнения домашнего повторения и аккуратного README. Пропущенная защита без уважительной причины означает, что работа возвращается на доработку. Апелляция подаётся в течение трёх рабочих дней после объявления результата.

Конкурс.
В конце семестра проводится конкурс: за шесть часов нужно собрать работающий прототип по заданию. Команда — до трёх человек, можно работать и одному. Конкурсная задача этого года: аватар-консультант, который отвечает на вопросы абитуриентов по документам приёмной комиссии. Разрешены готовые модели, но запрещены внешние платные API: всё должно работать локально, в том числе языковая модель qwen2.5 через Ollama. На конкурсе оценивают работающий прототип, README с инструкцией запуска и короткую защиту на три минуты.

Столовая и быт.
Столовая работает с 9:00 до 17:00, перерыв с 14:00 до 14:30. Буфет на первом этаже закрывается в 16:00. Справки для военкомата и прочие документы выдаёт деканат: приём с понедельника по пятницу, 9:00–16:00, обед 13:00–14:00. Справку готовят три рабочих дня, заказывать заранее. Библиотека открыта до 19:00, в субботу до 14:00.

Требования к работам.
Каждая лабораторная — отдельная папка lab_NN внутри репозитория. Внутри лежат скрипт, файл задания и артефакты, которые требует задание: картинки, сохранённые веса, таблицы с результатами. Все пути к данным считаются от расположения скрипта, поэтому запускать его можно из любого каталога. Вывод в консоль — на русском языке. Случайность фиксируется: random_state или seed, чтобы результат повторялся.

Пороговые значения.
Для MNIST зачётный порог — accuracy выше 97 процентов на тестовой выборке. Для сети с одним скрытым слоем на данных make_moons порог — выше 95 процентов: прямая линия даёт около 85 и этого недостаточно. Для мини-RAG достаточно recall@3 не ниже 0,8 и честного ответа «не знаю» на вопрос вне корпуса.

Правила по железу.
Ноутбуки приносить свои; на занятии можно пользоваться и стационарными компьютерами в аудитории 302. Устанавливать пакеты разрешено без ограничений, но требования к работам фиксируют версии в requirements.txt. Скачивать модели больше одного гигабайта на занятии не стоит: канал общий, лучше подготовиться заранее.
